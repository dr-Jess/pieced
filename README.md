# pieced
Pieced is a 3d AR motion boxing game, powered with only a phone and a laptop. This is the senior capstone project for Group 27 of the CIS Department @ University of Pennsylvania, 2026-27.

The repository is organized as follows:
- ios-app/ stores the source code for the ios-app which gathers and streams motion data
- game/ stores the source code for the core game
- analysis/ is a folder of various data, notebooks, etc. used for experimental data analysis
